# Support

Use GitHub Issues for this community port. Include your firmware version,
the port version, a short description and Chasm_TestLogs.zip if available.
Never upload commercial game files or save data. The supported game input
is exact Linux GOG Chasm 1.111 build 91697; unsupported builds fail preparation
without changing the original assemblies. Match the README folder layout.

Keep savedata when updating. A release requires its complete public runtime,
plus the user's own game files. Firmware provides SDL2/Wayland/ALSA; this
port does not install system packages or PortMaster.
